# YoluPainter

Unity Editor 内の専用ウィンドウで、同じレイヤーへ 2D と 3D から描くテクスチャ制作拡張です。現在は実装のプロトタイプで、完成版ではありません。

- Unity 2022.3 以降 / パッケージ名 `net.yozolab.yolupainter` / エディタ専用
- 依存パッケージ: com.unity.burst（1.8.7 以上）と com.unity.mathematics（1.2.6）。Unity のレジストリから自動で入る（どちらも Unity Companion License）。Unity 2022.3.22f1 ではエディタの決まりで Burst は 1.8.12 になる。無くても動く（.unitypackage で Assets に入れたときなど。CPU の合成の内側のループが Burst ではなく管理側のコードで動き、少し遅くなるだけ）。lilToon への出力は今後の範囲で、今は lilToon に依存していません

## 今あるもの

**画面と操作**
- ペイントソフトの画面: メニューバー、ツールの帯と描画色/背景色、ツールのオプションバー、2D と 3D を並べる・切り替える表示域、ドック（カラー・テクスチャセット・マテリアル・アセット・レイヤー・プロパティ）、ステータスバー。マテリアルのインスペクターはシェーダーの標準の UI を使い、ほかは自前の部品で描く
- ドックのパネルは左右の列のどこへでもドラッグで動かし、幅と高さを変え、畳み、タブでまとめ、別のウィンドウ（別のモニターや Unity のレイアウトにも置ける）に切り離せる。配置は描き手ごとに覚える。初めの配置（ウィンドウ ▸ パネルの配置を初期状態に戻す）は Substance Painter の並び: 左にアセットとカラー、中央に 2D と 3D、右に上からテクスチャセット、「レイヤー｜テクスチャセットの設定｜マテリアル」のタブ、プロパティ
- プロパティのパネル（Substance Painter のプロパティと同じく、選んでいる 1 つの物だけ）: 見出しに「プロパティ ― ブラシ」のように何の設定かが出る。描くツールなら、Substance と同じ「ブラシ｜アルファ｜ステンシル｜マテリアル」のタブ（「ブラシ」: サイズ・流量・不透明度（右のペンのボタンで筆圧に従わせる）・間隔・角度・進行方向・筆圧のカーブ・プリセットと、その中の小見出しのジッター・散布、テクスチャ、デュアルブラシ、色の変化、フェード・傾き。小見出しは右端のボタンで既定に戻せる。「アルファ」: 先端の見本と一覧（円形・内蔵・同梱・取り込んだブラシの先端。押すと先端だけを替える）・硬さ・真円率・取り込み）。スライダーは 1 行目に名前と値の箱（押すと数を打てる）、2 行目に全幅の溝。マスクに描くあいだは「マテリアル」の代わりに「マスク」のタブ（濃度・有効・反転・削除）。塗りつぶし・調整・グループのレイヤーの中身を選べばそのレイヤー（塗りつぶしは画像と投影も）、レイヤーの下のフィルター・Generator の行を選べばその段。選択・移動・パス・スポイトなどは、どのレイヤーを選んでいてもそのツールの設定。開いた見出しと見ていたタブは描き手ごとに覚える
- テクスチャセットの設定のパネル（Substance Painter の Texture Set Settings）: Normal の出力（Height → Normal・強さ・端・ファイルの Y の向き）、メッシュマップ（ベイクの窓を開く口と焼いたマップ）、スキンメッシュのモデルのポーズと BlendShape（モデル全体）
- 日本語と英語（ウィンドウ ▸ 言語。既定は Unity の言語に従う）。訳は `Editor/Localization/`（gettext の形式。DaerD と同じ作り）
- アイコンは Microsoft Fluent UI System Icons と Phosphor Icons（どちらも MIT、`Editor/UI/Icons/THIRD-PARTY-NOTICES.md`）。ツールのアイコンはツールの帯を右クリックして自分の PNG に差し替えられる
- ショートカットのガード: YoluPainter の窓にフォーカスがあるあいだ、Unity と他の拡張のショートカット（W で移動ツール、Ctrl+P で再生など）を止める（設定で「YoluPainter のキーだけ」「止めない」も選べる）
- カラーパネル: 四角と色相の帯、または色相の円。使った色の履歴
- 2D キャンバスの表示の回転と左右反転（表示だけで、描いた画素はそのまま）: - / ^（か =）で 15°、R を押したままドラッグか Shift ＋ 中ボタンのドラッグで自由に、Shift+R で回転を戻す、H で左右反転。ホイールの拡大はポインタの位置が中心
- 2D と 3D を並べる表示は、見出しのボタンか 表示 ▸ 2D と 3D を入れ替え で左右を入れ替え（Substance Painter のように 3D を左に）、境目のドラッグで幅を変えられる（ダブルクリックで半分）。2D キャンバスには今のテクスチャセットの UV のワイヤーフレームを重ねる（2D の見出しの右端か 表示 ▸ UV ワイヤーフレーム で切り替え）

**プロジェクトとテクスチャセット**
- Substance Painter と同じく、新規プロジェクトでモデル・テンプレート（使うチャンネル）・解像度・ノーマルマップの形式を選び、モデルのマテリアルごとにテクスチャセットを作る（同じマテリアルを使うメッシュ・サブメッシュは 1 つのセットで、どちらの面にも描けて、焼くと両方が入る。マテリアルの無いスロットは 1 つの「未割り当て」。一覧には使っているメッシュの名前を添える）。セットごとに文書・レイヤー・Undo・選択範囲・メッシュマップを持ち、パネルか 3D ビューでのダブルクリックで切り替える。セットごとの解像度はプロジェクト設定で後から変えられる（画素は再標本化。元に戻せないので確かめてから）
- モデルの差し替え（Substance Painter のメッシュの読み直し）: プロジェクト設定かテクスチャセットのパネルでモデルを替える、または書き出し直した FBX をプロジェクト設定の読み直しのボタンで読み直すと、何が変わるかの一覧を確かめてから、描いたものを保ったまま新しいモデルに付け替える。テクスチャセットはマテリアル（アセットが同じなら同じ、違えば名前）で付き直し、画素は変えない（UV が同じなら見た目も同じ、違えばそう知らせる）。新しいモデルに無いマテリアルのセットは残し、セットの無い新しいマテリアルには空のセットを足すかを尋ねる。3D のパスは新しいメッシュに描き直し、描けなければ画素にして知らせる。焼いたメッシュマップは古くなる（焼き直す）。差し替えは元に戻せない（各セットの画素と Undo の履歴は残る）
- 3D ビューは全部のセットを見せ、描けるのは今のセット。表示は「中立」と「マテリアル」（元のマテリアルの複製に塗ったテクスチャを差し込む。lilToon 2.3.4 とビルトインの Standard は確かめた対応、それ以外は Color だけ）
- マテリアルの欄: 保存しない複製を、そのシェーダーのインスペクター（lilToon なら lilToon の UI）で調整する。上に元のマテリアル・シェーダー・塗ったチャンネルの流し込み先・変更数を表示。「全部元に戻す」で取り消し、「マテリアルに反映…」で一覧を確かめてから元のマテリアルへ書く（Unity の Undo で戻せる）。塗ったテクスチャは表示時に優先し、インスペクターで選んだテクスチャは下地として覚える。流し込み先は上のボタンから手で変更できる
- 2D・3D ビューそれぞれの上の中央に今の表示名のドロップダウン。「マテリアル」（2D は今の合成）、6 チャンネルと選んだ層のマスク、焼いたメッシュマップを別々に選べる（未ベイクは理由付きで無効）。表示を変えても描き込み先は変わらない。ポインタのビューで C はチャンネルを順に、Shift+B はメッシュマップを順に、Shift+C はマテリアルに戻す。ストロークの最中は切り替えない
- 擬似的なシーン: カメラのプリセット（前・後ろ・左・右・上）、照明のプリセットと向き・強さ・色、環境光、背景
- アセットのパネル（Substance Painter のシェルフに当たる）: 「このプロジェクト」「Unity のプロジェクト」「自分の置き場」「内蔵」の画像を名前で探し、
  サムネイルで選ぶ。取り込むと `.ylp` に写しを埋め込み（全部のテクスチャセットで共通のリソース）、Unity のテクスチャなら参照（GUID）も持つ。
  元のテクスチャとインポート設定は変えない（読み取りが許されていないものは GPU で写して読む）。出どころが変われば、開いたときやパネルを出したときに
  知らせ、更新するか選べる（自動では置き換えない。消えても写しで使える）。リソースはダブルクリック・ボタン・キャンバスへのドラッグで
  今のチャンネルの新しいレイヤーとして置く（テクスチャセットの大きさに合わせる。1 回の Undo）。3D ビューのモデルへドラッグすると、落とした所の
  面に向けたデカールとして置く（下）。自分の置き場は個人の設定のフォルダで、ほかのプロジェクトと同じフォルダを指せば共有できる
- デカール（Substance Painter の平面の投影で切り抜いて貼るのと同じ）: 画像をモデルの面に貼る、後から動かし直せるレイヤー。層を選んでいる間は
  3D ビューにギズモが出て（マスクの編集中は出ない。Q で隠す・出す）、位置・回転・大きさを動かし（1 回の Undo、Esc で戻す）、画像のアルファで形を切り抜き、ボックスの奥行きと面の向きで裏側・遠い面には出さない。
  色だけでなく Roughness・Height などのチャンネルにも画像か値を持て、値は画像の形の中に出る。2D キャンバスには届く範囲を重ねる。焼いた
  Position と World Normal のメッシュマップを読む（無ければ投影の欄のボタンで焼く）

- アセットの種類は画像・ブラシ・マテリアル・スマートマテリアル・スマートマスク。レイヤーメニューの「ブラシをアセットへ保存」「マテリアルをアセットへ保存」で現在の設定を残せる。
  ブラシは設定と筆先・紙の質感を `.ylbrush` と `.ylp` に保持し、ダブルクリックで選ぶ。マテリアルは塗るチャンネル値と画像の写しを塗りつぶしレイヤーへ置く。
  Unity のマテリアルの取り込みは確認済みの Standard・lilToon の対応を使う。シェーダーの効果、元のテクスチャの変換、法線や高さのシェーダー固有の倍率は複製しない。
  Unity のサブアセットの画像は GUID とファイル内の ID で識別する。法線マップは Unity の保存上の詰め方を復号し、XYZ の RGB として取り込む。
- 自分の置き場は下位フォルダも表示する。右クリックの「名前を変更…」「削除…」は確認後に実行する（Undo はできない）。プロジェクトの写しと配置済みの層は変わらない。
  `.ylsmart` は Unity のアセットとしても並び、インスペクターで内容と球のサムネイルを見られる。大きなスマートマテリアルの保存は背景で進み、アセットのパネルで取り消せる。
  取り込み時にはメモリ予算と `.ylp` の 768 MiB 上限を現在の文書・合成・リソースの量で確認する。追加後の編集による増加とディスクの空きは別に扱う。

**描く**
- 疎な RGBA8 タイルを正本にした描画、ストローク単位の正確な Undo/Redo/取消。2D キャンバスと、隔離した 3D プレビューの面の上（可視性・連結性・UV の継ぎ目を調べる）の両方から同じレイヤーへ描く
- ブラシ: 丸/画像の筆先、硬さ・間隔・角度・丸さ・ゆらぎ・散布・紙の質感、筆圧（カーブは欄の中で編集）・傾き、手ぶれ補正と入り抜き、速く描いても折れ線にならない曲線の補間、カラーダイナミクス、デュアルブラシ。内蔵 13 種と Krita 4 既定の筆先 76 種（CC0、`BrushSets~/`）。GIMP（.gbr / .gih / .vbr）・Photoshop（.abr / .pat）・PNG の取り込み
- コピースタンプ（S）: 2D/3D のビューを Alt＋クリックして写し元を指定し、同じビューで描く。「全表示レイヤーを参照」は描き始める前のチャンネル合成を写す（マスクは現在のマスク）。位置合わせを切るとストロークごとに写し元から始める。ぼかし（U）は UV の画素近傍、指先（Shift+U）は 3D のつながった面に沿って UV の継ぎ目と鏡映した島をまたぐ。非連結の面では拾い直す
- ツール: バケツ・グラデーション・矩形/楕円/投げ縄選択・マジックワンド・ID の色で選択（Shift+W。焼いた ID マップの部品の色を 2D でも 3D でもクリックで選ぶ）・移動と自由変形・パス（2D と 3D の編集できる筆跡）・スポイト、3D ビューでの三角形・UV アイランド・メッシュ・マテリアル単位の選択と塗りつぶし、選択範囲の拡張・縮小・境界・ぼかし
- ブラシの「マテリアル」で塗るチャンネルと値を選ぶと、ブラシ・バケツ・グラデーション・ポリゴン塗りつぶし（4）・パス（P）が組全体を描く（1 回の Undo）。消すと組の全部を消す。ブラシ・範囲ツールはマスクの編集中にはマスクだけを変える（パスはマスクを編集しない）。パスは作成時の組を保存し、点の編集でも保つ。「ブラシを使用」で今の組へ差し替える。グラデーションのプロパティで「二つのマテリアルの間」をオンにし、「今のマテリアルを終点にする」か終点の各値を指定すると、その組へ補間する（オフでは透明へ）
- シンメトリー（ブラシのオプションバーの右端の切り替えと ▾ の小さな窓。手ぶれ補正・入り抜きも同じくオプションバー）: 3D はモデルのルートのローカル X/Y/Z に直交する面での鏡映と、ルートの X/Y/Z 軸のまわりの放射状（2〜16 個）。鏡映と放射状を合わせると最大 N × 2 個。対称先は今のテクスチャセットの同じレンダラーの面へ置き直す。「可視性を無視」を有効にすると対称先の裏側・隠れた面にも塗る（元のダブは見える面だけ）。2D は動かせる縦・横・両方の線、または中心のまわりの放射状（2〜16 個）。文書の画素座標なので表示の回転・反転に左右されない。重なりは覆いの大きいほうで 1 回だけ、ストローク全体が 1 回の Undo、Esc・フォーカス喪失・予算超過で全取消。選択範囲・ロック・マスク・マテリアルの複数チャンネルとぼかしに対応。指先とクローンとの併用は読み元と移動方向を対称先ごとに扱えないため理由を表示して断る。設定はブラシとプロジェクトに保存し、軸は表示を切り替えられる。パス・選択・バケツには対称を適用しない。3D ビューの見出しでも鏡映を切り替えられる
- ステンシル（Substance Painter のステンシル）: このプロジェクトの画像を 2D キャンバスと 3D ビューの画面に半透明で重ね、ブラシはその上から塗る（プロパティのブラシの「ステンシル」のタブ。アセットのパネルからドロップするか、押して選ぶ）。画面に貼り付いたまま（カメラを回しても、キャンバスを動かしても同じ所）。T を押したままドラッグで、左 = 回す（Shift で 15° 刻み）、中か Ctrl+左 = 動かす、右か Alt+左 = 大きさ（Substance の S と同じ割り当て。S はコピースタンプなので T）。N を押しているあいだは使わずに塗る。灰色の画像は塗る量（白は通し、黒と透明は止める。反転も選べる）、色の画像はその色で塗る（アルファが量。マテリアルで塗るときは Base Color に画像の色、ほかのチャンネルは自分の値を画像のアルファの量で）。横・縦・両方の繰り返し。置き場は窓の状態で、`.ylp` やブラシのプリセットには入らない（画像がプロジェクトから消えたら外して知らせる）
- 3D のピックは、ポリゴン塗りつぶし・選択・バケツ・ID の色で選択と Generator の ID スポイトで、ポインタの下の対象を薄い色とワイヤーで強調する。ID の強調はクリックと同じマップ・許容の幅を使う。2D のポリゴン塗りつぶしで UV が重なるときは、Tab／Shift+Tab・右クリック、またはオプションバーの「UV の重なり」で候補を選ぶ。共有 UV の画素は、選んだ候補以外の面にも反映される
- ID のベイクの「色分けの元」には「マテリアルのアセット」も選べる（同じアセットならスロットやレンダラーが違っても同じ色。名前が同じだけの別アセットは別の色）。ID のベイクの窓か、ID 選択ツールのプロパティの「部品の ID 色を指定」で、このセットのメッシュの塊ごとに色を指定できる。指定した色は生成元や高ポリの色より優先され、同じ色はまとめて選択される。変更後は ID をベイクし直す。色の指定は .ylp に保存され、Ctrl+Z で戻せる。モデルの UV・スロット・レンダラーや塊の対応が違うときは、リセットするまで ID のベイクを断る
- レイヤー: グループ、26 の合成モード、ラスターマスク、Fill レイヤー、調整レイヤー（反転・レベル補正・色相/彩度/明度）、クリッピング、複製（Ctrl+J、グループは中身ごと）、結合（下のレイヤーと・グループを・表示レイヤーを。前後の合成を比べ、見た目が丸めより大きく変わるなら確かめる）、コピー・結合部分をコピー・カット・新しいレイヤーとしてペースト（窓とテクスチャセットをまたぐ）、フィルターのスタック、Generator（焼いたメッシュマップから摩耗・汚れ・勾配・向き・厚みの値を作る段。マスクにも層の画素にも置ける。形のグラデーション: 3D ビューのギズモで動かすボックス・球・平面の範囲から値を作り、シーンの物の BoxCollider・SphereCollider・Transform の形を読むだけで写せる。ID の色: ID マップの部品の色をスポイトで 2D・3D から取り、その部品だけを見せる。アンカー: 下の層の合成（Height など）やマスクに名前を付けて置き、上の層のマスクや画素の Generator の入力にする。並べ替えで上下が逆になれば理由を出して入力のまま通す）、チャンネル別ソース（Color / Roughness / Metallic / Height / Normal / Emission。Height から Normal を導出）。フィルターと Generator はレイヤーの行の下に字下げした行で並び（Substance Painter の効果の行）、目で有効を切り替え、選んだ行の ▲▼× で並べ替え・削除、右クリックで足す・焼き込む。マスクはレイヤーの行のマスクのサムネイルを押して描き、右クリックで有効・反転・削除・マスクへのフィルター。「このチャンネルを描く」とチャンネルごとの合成を戻すのはレイヤーの右クリック。複数選択（Ctrl・Shift クリック。まとめて削除・グループ化・複製・結合・表示・移動）と、ロック 4 種（透明ピクセル・画像・位置・すべて。PSD の lspf と読み書き）
- メッシュマップのベイク（Substance の Baker と同じ配置の窓。法線・位置・AO・曲率・厚み・接空間の法線・高さ・ID・ベントノーマル・不透明度、高ポリの参照、GPU の計算シェーダー）
- 速さ: Core の CPU の処理はタイルと行の束で並列（出力はスレッド数に依らずバイト一致）。表示の合成は 自動 / GPU / CPU から選べる。3D のダブの遮蔽のレイも並列で、ストロークの間は見え方を覚える

**保存と連携**
- 原画素を保持する独自形式 `.ylp`（形式の版と保存したアプリの版を記録し、古い形式は開くときに移す。`Documentation~/YLP_FORMAT.md`）、チェックサム付きの世代保存、保存途中の障害・外部改変の拒否、復旧の checkpoint
- 制限を明確にした RGB8 ラスター PSD の読み書き（未対応の情報があれば編集を禁止して原本を守る）、チャンネルごとの PNG の書き出し、lilToon のマテリアルへの割り当て（確かめた版・バリアントだけ）。書き出しのテンプレート（Unity Standard / URP Lit・HDRP Lit・lilToon 向けに、Metallic と Smoothness・MaskMap・焼いた AO などを詰めた PNG）。書き出しでは UV の外へ色を塗り広げる（パディング。既定は届くかぎり全部、プロジェクト設定で 0〜64 テクセルか全部。Unity のミップマップで UV の境目に背景がにじまない）
- プラグインの受け口（試作 API 0.1）: `Yozolab.YoluPainter.Api` を参照するアセンブリでメニューのコマンドとツールのアイコンを足し、開いているプロジェクトを読んだり層を足したりできる。書き方は `Documentation~/PLUGIN_API.md`

正本を作るのは **CPU のブラシ**です。GPU は表示の合成・メッシュマップのベイク・Normal の出力に使い、保存の唯一の正本にはしません。

形のグラデーションを塗りつぶしへ直接置くには、そのレイヤーを選び、プロパティのチャンネルの欄で「ワールドスペースの勾配を追加」を押します。
上の列は不透明度、下の列は色（Roughness・Metallic・Height では値）の分岐点です。空いている所をクリックすると追加、ドラッグで移動、右クリックか
枠外へドラッグすると削除できます（各列2〜32点）。小さい中点の印で区間の半分になる位置を変え、下の「値のカーブ」で形の値を勾配上の位置へ
写します。点とカーブは離したときに確定し、Escape・フォーカス喪失で取り消します。3D の編集をオンにすると、Ctrl で Unity のシーンの設定に従い
移動・大きさ・回転を刻み、Shift で大きさを両面から変えます。ハンドルはモデルの手前に表示します。Position マップが無い・古い場合は理由と
代わりの一定値を表示します。画像と勾配はチャンネルごとに切り替え、Undo で元へ戻せます。

RGB は sRGB の格納値で補間し、不透明度は独立して補間します。[Photoshop の Classic](https://helpx.adobe.com/ie/photoshop/using/gradient-interpolation.html)
を基準に、従来の色の勾配と透明側の RGB を保つためです。中点は区間の重みの半分を指定する2本の直線、値のカーブは筆圧と同じ、点の間で
行き過ぎない補間です。Photoshop の Linear・Perceptual と同じ出力や、Photoshop 実機との画素一致は確認していません。

## 導入（対象: Unity 2022.3）

1. 入れ方は次のどれか
   - **VCC（VRChat Creator Companion）**: Settings ▸ Packages ▸ Add Repository で `https://vpm.yozolab.net/index.json` を足し、プロジェクトの
     Manage Project で YoluPainter を追加する
   - **Release の .zip / .unitypackage**: GitHub の Releases から取り、.zip は Packages の下に展開、.unitypackage は取り込む
   - **Package Manager**: `+` → Add package from git URL で `https://github.com/YozoraKurage/YoluPainter.git`（または Add package from
     disk でこのリポジトリの `package.json`）
2. メニュー `YozoLab → YoluPainter (Prototype)` を開く
3. ファイル ▸ 新規プロジェクト… でモデル（プレハブかモデルアセット）とテクスチャセットにするマテリアルを選ぶ。モデル無しでも 2D だけで描ける。3D ▸ デモのキューブ で検証用の 6 つの UV 島を持つキューブも読める
4. 描いて、ファイル ▸ 保存（.ylp）。画像は ファイル ▸ 書き出し で PNG に

大きなモデルは、表示用の写しを用意してから当たり判定を別スレッドで準備します。進み具合の横の「準備を取り消す」で止め、「もう一度準備する」でやり直せます。準備中もモデルの表示と2Dの描画・レイヤー操作は使えます。3Dでは準備が終わってから描けます。ほかのテクスチャセットの表示は少しずつ更新されます。

Read/Write が無効のメッシュも、エディタの読み取り用APIで読みます。読めなかった場合は診断に設定の案内が出ます。

モデルの Read/Write 設定を自動で変えたり、シーンのマテリアルへ勝手にテクスチャを割り当てたりはしません。プレビューは自分で作ったメッシュとマテリアルの複製だけを使います。元のマテリアルへ書くのは「マテリアルに反映…」と lilToon への割り当てで、どちらも確かめてから行います。

## 検証の範囲と分かっている制限（0.1.0）

- 試験（EditMode の 1,400 件あまり）は、Linux の devcontainer の Unity 2022.3.22f1（GPU はホストの実 GPU を WSL2 の d3d12 経由の
  OpenGL 4.6 で）で回している。**Windows の D3D11・Mac の Metal では、ほとんど確かめていない**。描画・GPU の合成・3D ビューの見え方は、
  Windows で違う所があり得る（見つけたら知らせてください）。
- 実機のペンタブ・液タブは、作者の Windows 以外では確かめていない。筆圧・傾きは Unity のエディタの窓のイベント（Windows Ink）で読む。
- PSD の読み書きは psd-tools で確かめた範囲で、Photoshop・CLIP STUDIO の実機での往復は確かめていない。未対応の情報は黙って捨てずに知らせる。
- `.ylp` の正本は機能を足すたびに版が上がり、**新しい版で保存したファイルは古い YoluPainter では開けない**（開くのを断るだけで、ファイルは
  壊さない）。保存の前に退避（バックアップ）を残す設定は Project Settings ▸ YoluPainter。
- プロトタイプなので、操作・保存の形・API は 0.x のあいだに変わり得る。大事なテクスチャは PNG にも書き出しておく。

## 保存（.ylp）

YoluPainter のファイルは `.ylp` です（CLIP STUDIO の .clip、Photoshop の .psd に当たる 1 ファイル）。中身は zip で、拡張子を .zip に変えれば普通のツールでも中を確認できます。形式の詳しい決まりは `Documentation~/YLP_FORMAT.md` にあります。

- `ylp.json`: 中身の形式の版と、保存した・作った YoluPainter と Unity の版。自分より新しい形式は、書いた版を示して開くのを断ります
- `project.json` と `sets/<ID>/`: テクスチャセットの並びと、セットごとの正本 `document.utpaint`（マスク・Fill・調整・クリッピング・パスを含めてロスなし）・選択範囲・合成済みの画像・焼いたメッシュマップ
- `resources.json` と `resources/<中身の SHA-256>.png`: プロジェクトのリソース（アセットのパネルで取り込んだ画像）の並びと、写しの画素。出どころ（Unity の GUID・ファイル・自分の置き場・内蔵）も記録する
- `view.json`・`brush.json`・`thumbnail.png`
- 先頭の `mimetype`（無圧縮）と、全エントリーの SHA-256 を並べた `manifest.sha256`。読むときに全部確かめ、合わなければ開きません

保存は、作って読み直して確かめた一時ファイル（名前が `~` で終わるので Unity は取り込まない）から最後に 1 回だけ置き換えます。途中で失敗しても元のファイルはそのままです。

- 上書き保存すると、直前の版を隣の `<名前>.ylp-backups~/` に退避します。何世代残すかは設定で選べ、既定はすべて残します（バージョン管理に入れたくなければ `*.ylp-backups~/` を ignore してください）
- 開いた/保存した時点から外でファイルが変わっていると、通常の保存を拒否します（Save As は可）。差分表示・マージは未実装です
- `.ylp` を Assets に置くと、Project ウィンドウにサムネイルと大きさ・チャンネル・テクスチャセット・形式の版が出て、ダブルクリックで YoluPainter が開きます。テクスチャは出しません（.ylp は作業ファイルで、配布先に YoluPainter があるとは限らないため。マテリアルには書き出した PNG を使う）
- PSD は「Export PSD」で今のセットの選んだチャンネルを書き出します。PSD で表せないものがあると、平らにせず理由を示して書き出しません。取り込んだ PSD を直接上書きせず、元のバイト列を `.ylp` の中に保持します
- 未保存の作業の復旧 checkpoint は Unity プロジェクトの `Library/YoluPainter` 配下へ 15 秒ごと（設定で 5〜600 秒）、フォーカス喪失・リロード時にも保存します。突然のプロセス停止では最後の正常 checkpoint までです
- 通常の checkpoint は写しを取って背後で保存し、保存中も描けます。書き込み中の次の要求は最新の一つだけを待たせます。閉じる・別文書を開く・リロード・Play の前は書き切るまで待ちます。失敗は通知し、次の保存時に再試行します
- 復旧の世代は既定で 3 つ（設定で最低 2）残し、同じ内容のセットや画像は世代間で共有します。新しい checkpoint の保存が完了してから古い世代を整理します
- 保存済みか作った直後のままのウィンドウを閉じると、その復旧フォルダを片付けます。未保存の作業は残り、**ファイル ▸ 復旧…** で日時・プロジェクト名・容量を見て復旧か破棄を選べます。復旧したら `.ylp` として保存してください。破棄は元に戻せません
- `Library/YoluPainter` の合計が容量の通知目安（既定 2 GiB）を超えるとステータスバーと復旧の一覧で知らせます。未保存の作業を容量のために自動で破棄しません

## 設定

ウィンドウのメニューの ファイル ▸ プロジェクト設定… / 編集 ▸ 環境設定…、または Project Settings > YoluPainter で開きます。

- **プロジェクトで共有**（`ProjectSettings/Packages/net.yozolab.yolupainter/Settings.json`、バージョン管理に入る）: 新規ドキュメントの既定の大きさ、書き出しのパディング、共有のブラシ置き場
- **自分だけ**（`UserSettings/YoluPainter/Settings.json`）: 取り込んだブラシの置き場、自分の置き場（アセットのパネル。既定は `UserSettings/YoluPainter/Library`）、同梱ブラシの表示、`.ylp` のバックアップを残す数、復旧 checkpoint の間隔・残す世代の数・容量の通知目安、メモリの予算、Unity のショートカットを止めるか、表示の合成（自動 / GPU / CPU）と CPU のスレッド数

ブラシ置き場と自分の置き場は Unity に取り込まれないよう、Assets / Packages の下（名前が `~` で終わるフォルダの中を除く）は指定できません。メモリの予算には、プロジェクトのリソース（埋め込んだ画像の画素）の上限もあります。
